# ShutUpAI

热爱 AI，但不惯着 AI。

We Love AI. We Just Tell It to Shut Up.

品牌主页：https://www.shutupai.com/

## 品牌态度

- **狂热**：坚定 All in AI，相信 AI 会改变世界。
- **清醒**：不迷信 AI，不接受 AI 一本正经地胡说八道。
- **犀利**：敢吐槽、敢质疑、敢说真话。

**Don't Hate AI. Challenge AI.**

不是讨厌 AI，而是挑战 AI。

## 本地预览

纯静态页面，无需安装依赖或构建。在项目目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 http://127.0.0.1:4173 。

## 文件

- `index.html`：页面结构、品牌文案及搜索分享元信息。
- `styles.css`：桌面与移动端样式，支持减少动态效果偏好。
- `script.js`：每次打开时读取浏览器语言（中文使用中文，其他语言使用英文），支持当次手动切换；另含入场与滚动动画及页脚年份更新。
- `favicon.svg`：品牌图标。
- `CNAME`：保留现有自定义域名配置。
- `assets/fonts/`：本地托管的 Manrope 字体及 OFL 开源许可证。
